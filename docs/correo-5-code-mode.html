Doscientas tools no caben

Hola Geek 👋🏼

Conectas veinte herramientas por MCP y las veinte definiciones entran al contexto antes de que el agente haga nada. Con doscientas, gasta media ventana leyendo el menú. 🎬

{{video}}

En corto:

▸ El menú es la mitad del costo. La otra mitad son los resultados: la transcripción entra al contexto cuando el agente la lee, y vuelve a entrar cuando la escribe en la llamada siguiente. Una junta de dos horas, cincuenta mil tokens extra.
▸ Con code mode las herramientas dejan de ser un menú y pasan a ser archivos que el agente importa: drive.ts, crm.ts. Carga las dos que va a usar, no las doscientas.
▸ Y los datos se quedan en la ejecución. Anthropic midió el mismo flujo de las dos formas: 150,000 tokens contra 2,000. El mismo trabajo, sin pasarlo todo por el contexto.

El precio es que alguien tiene que ejecutar ese código, y lo escribió un modelo. Por eso el sandbox no es un extra: es el piso. En el taller montamos el nuestro. 📦⚙️🤖
