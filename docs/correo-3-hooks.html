Te dejo lo que prometí: el mismo guardrail —bloquear un rm -rf— escrito para tres arneses distintos.

Claude Code
// .claude/settings.json
"PreToolUse": [{ "matcher": "Bash",
  "hooks": [{ "command": "./guard.sh" }] }]

# guard.sh · exit 2 bloquea la llamada
grep -q 'rm -rf' && exit 2
LangChain · LangGraph
class Guard(AgentMiddleware):
  def wrap_tool_call(self, req, handler):
    if "rm -rf" in str(req.tool_call["args"]):
      return "Bloqueado."
    return handler(req)
OpenAI Agents SDK
class Guard(RunHooks):
  async def on_tool_start(self, ctx, agent, tool):
    if tool.name == "bash":
      raise Tripwire("Bloqueado.")
